# Synthetic practice only

Create a disposable vault with Start and select `opportunity`, `workshop`, `functional-design`,
`decision`, `handover`, `debrief` and `closeout`. Use a fictional multi-plant manufacturer.

Practice a planner reporting 120 on-hand units with release status unknown, followed by quality
evidence that only 60 are released. These counts can coexist; do not treat different inventory
states as a contradiction. Keep both attributed accounts. A derived claim that all 120 units are
allocatable needs correction; the original on-hand observation need not be false. Do not approve
a 100-unit allocation without resolving the rule and evidence. Carry owned gaps into handover.

These are exercise instructions, not observed client facts, accepted requirements or receipts.
No example files are installed by the template manifest. Actual qualification retains separate
fixture expectations, evidence and independent review in the host development repository.
