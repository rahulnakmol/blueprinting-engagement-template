# Dependency

**Purpose:** Record one thing the engagement needs from someone else to proceed.

## Description
State what is needed, from which `organizations`, by when (`due`) and what it `affects`. Set `dependency_type`.

## Status
Name the `owner` tracking it and record commitments received with their source. An unconfirmed dependency is a risk.
