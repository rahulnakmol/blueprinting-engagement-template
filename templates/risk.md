# Risk

**Purpose:** Record one uncertain event that would harm an outcome if it happened.

## Description
State the cause, the event and its consequence. List what it threatens in `affects`.

## Assessment and response
Rate `likelihood` and `impact` with the basis for each. Set the `response` (avoid, mitigate, transfer or accept), the mitigation actions, the `owner` and the review `due` date.

## Evidence
List the `findings` and `sources` that raised it.
