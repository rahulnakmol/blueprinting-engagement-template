# System

**Purpose:** Record an application, module, spreadsheet or manual tool as functional context. This is not a technical architecture.

## Identity
Set `system_type`, `vendor`, `module` and `lifecycle` (current, target, retire or unknown). List the `organizations` that use or own it.

## Functional role
Describe which `capabilities` it supports, what users do in it, its known functional limits and workarounds, and the `findings` that describe them. Technical questions become explicit questions for the appropriate specialist.
