# Action

**Purpose:** Record one owned follow-up with a due date.

## Action
State what will be done, the expected result and what it `affects`. Link the `decisions` or `questions` that created it.

## Ownership
Name the accepting `owner` and the agreed `due` date. An action nobody has accepted stays `owner: unassigned`. Sending a follow-up message completes that action only, not the underlying decision.
